# Flying Legends Follower

Live flight tracker for the P-51D Mustang **Frances Dell** (OO-NZW), built with Hercules.

**Live app:** https://flying-legends.onhercules.app/

## Features
- Live position, altitude, speed and heading of Frances Dell (free ADSB.lol data, no API key needed)
- Status: Hangar, taxiing, airborne, landed, with sound and animations
- Map with flight trail and place name
- "Letzte Flüge": the last recorded flights with duration, max altitude and speed
- Automatic background recording every 30 minutes, Friday to Sunday (Vienna time), even when the app is closed
- Push notifications and email alerts when she starts, takes off and lands
- Track any other aircraft by callsign, registration or ICAO24 code
- Installable on phone and desktop (PWA)
